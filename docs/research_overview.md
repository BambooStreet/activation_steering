# 연구 개요

> ⚠️ **방향 전환됨**: 이 문서는 **원 모듈식 계획**(배경)이다. 모듈 4b에서 behavior↔self-report 해리를 발견해
> 연구 초점이 그 조사로 이동했다. **현재 상태·로드맵은 [STATUS.md](STATUS.md) 먼저 읽기.**
> (또한 페르소나 모델은 본문의 "Gemma 2 2B"가 아니라 실제로는 **gemma-2-9b-it, layer 20**.)

## 문제의식
LLM으로 "가상 설문 참가자(페르소나)"를 만들어 인간 실험을 시뮬레이션하려는 시도가
많지만, 성격 주입이 거의 프롬프트 기반("당신은 외향적입니다")이다. 프롬프트 성격은
(1) 긴 대화에서 드리프트하고 (2) 성격 자기보고가 실제 행동과 어긋난다. 대안으로
**활성화 스티어링**(내부 활성화에 외향성 방향 벡터를 더함)을 검증한다.

## 주장의 형태 (중요)
"스티어링 > 프롬프트"가 아니라 **"조건부 지도 + 드리프트 프레임"** — 각 방법이 어떤
조건에서 강/약한지 규명하고, 스티어링이 인과적으로 더 깨끗한(드리프트 적은) 영역을 식별.

## 파일럿이 답할 3가지 (= 존재 이유)
1. **척도 효과 (A)**: 스티어링이 Mini-IPIP 외향성 점수를 실제로 움직이는가
2. **행동 효과 (B)**: 척도만 바꾸나 vs 대화 행동까지 바꾸나 — 어긋나면 *personality illusion*
3. **멀티턴 안정성 (C)**: 특히 CAA가 긴 대화에서 무너지는가

> 게이트: A·B·C 통과 못 하면 나머지는 무의미. 화려한 결과가 아니라 이 3개를 깨끗이 확인.

## 재현 대상 — Vibe Check (Rahman & Desai, CHI 2026)
인간 150명 × 챗봇(성격강도 Low/Med/High)로 뉴욕 당일여행 계획. 사후 6개 척도
(Trust/Likeability/Intelligence/Enjoyment/Anthropomorphism/Intention to Adopt) + 본인
Mini-IPIP. 핵심결과: (a) 역U자(Medium 최고), (b) 사용자–챗봇 성격 정렬↑→평가↑,
(c) 외향성·정서안정성 최대 영향. 이 인간 결과를 ground truth로, 인간 자리에 LLM 페르소나.

**파일럿 RQ 범위**: 외향성 단일 축 → 부분 재현. RQ1 역U자는 챗봇(IV) 쪽에서,
RQ2·3·4는 외향성 부분집합으로만. 완전 재현은 본 실험(Big Five 확장) 시.

## 실험 변수 구조
- **IV (챗봇)**: 성격강도 Low/Med/High. **GPT-4o + 원논문 TMK 프롬프트 고정, 스티어링 안 함.**
- **MV (페르소나, 조작 대상)**: 외향성만. **Gemma 2 2B**(오픈 모델 — 내부 활성화 접근 필요).
- **DV**: 6개 자기보고 척도(페르소나가 챗봇 평가) + 대화 행동 지표 — 이중 측정(가설2).
- 챗봇(GPT-4o)과 페르소나(Gemma 2 2B)는 다른 모델, 멀티턴 대화.

## 페르소나 4조건 (격리 설계)
| 조건 | 프롬프트 성격 | 스티어링 성격 |
|---|---|---|
| 0 baseline | ✗ | ✗ |
| 1 프롬프트만 | ✓ | ✗ |
| 2 스티어링만 | ✗ | ✓ |
| 3 둘다 | ✓ | ✓ |

공통 프롬프트 틀을 **글자 그대로 동일**하게, 주입 경로만 다르게 → `0 vs 2`=순수 스티어링,
`0 vs 1`=순수 프롬프트, `1 vs 2`=직접비교. 외향성은 양방향(`+α`=외향, `−α`=내향).

## 스티어링 방법
- **벡터 추출**: difference-of-means (CAA). NEO-PI 외향성 6 facet 대조 쌍, minimal-edit.
- **정제**: mean-centering + L2 정규화.
- **주입**: 단일 중간 레이어에만 `h' = h + α·v` (전 레이어 주입 금지 — 멀티턴 붕괴).
- **순서**: CAA 먼저 → 이후 기성 SAE(Gemma Scope)로 벡터 추출만 교체해 멀티턴 안정성 비교.

## A·B·C 측정 — 2단계 구조
- **1단계 게이트(모듈 5)**: 페르소나 단독 α-sweep으로 A·B·C 측정 → **go/no-go**. 통과 못 하면 중단.
- **2단계 본 대화(모듈 8·9)**: 실제 24턴 Vibe Check 대화에서 B·C 재측정(가설3 진짜 검증).
- 판정: A 단조증가→걱정1 해소. A·B 동행→걱정2 해소(illusion 아님). A만 움직임→illusion 소견. C→걱정3.

## 파일럿 vs 본 실험
- **파일럿(현재)**: 외향성 단일 축, 인구통계 제외. 목적 = 3가지 확인 + 파이프라인 검증.
- **본 실험(나중)**: Big Five 전체, 인구통계 투입, 사람 검증 추가.

## 모듈 로드맵 (알려진 앵커)
- **모듈 1**: 대조 쌍 생성 ✅ (본 문서셋)
- **모듈 2**: 검증(생성과 다른 모델로 스크리닝) — 다음
- **모듈 5**: A·B·C go/no-go 게이트
- **모듈 8·9**: 본 Vibe Check 대화 + B·C 재측정
- (나머지 모듈은 받을 때 확정)
