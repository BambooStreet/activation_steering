# Phase 4b — Qwen α 수정 · 채널 플립 발견 (표준화 벡터)

> 실행 2026-07-12(콘솔 로그 기준; steer JSON은 세션 내). 선행: [phase4_crossmodel_behavior.md](phase4_crossmodel_behavior.md)(1차: Gemma/Mistral 착시, Qwen 무효).
> 핵심: Qwen "통합" 해석 **기각**(표준화 아티팩트) + **표준화가 행동채널→자기보고채널로 바꾼다**는 예상 못한 발견.

## 경위
1차 Qwen 무효(생성 붕괴, cos_V_cue 0.018) → 수리 시도.
- **표준화 추출**(`build_vectors --standardize`)로 거대활성 다운웨이트 → 벡터 내부일관성(cos_V1_V2 0.96)은 회복.
- 그러나 기본 스윕(α=c·R, R=858)에선 **여전히 붕괴**. 진단: **α 과대**(R=858이 거대차원으로 뻥튀기) → 작은 α로 재시도.

## 발견 1 — 진짜 문제는 α 스케일 (벡터 방향은 OK)
작은 α(±17~86)에서 Qwen이 **코헤런트하게 스티어링**(rep 0.00, 실문장). 행동 dose-corr **+0.94**.
⇒ 표준화 벡터 방향은 쓸 만했고, **R=858 기반 α가 모델을 부순 것**. (교훈: 거대활성 모델은 α를 R로 스케일하면 과주입.)
- **cos_V_cue(0.021)는 표준화 벡터에 무효 지표** — z-공간 벡터를 raw cue와 비교한 좌표 불일치. 코헤런트 스티어링이 벡터 유효성을 증명.

## 발견 2 — Qwen 자기보고가 행동 따라 움직임 (잠정 "통합" 떡밥)
조밀 스윕(α −17~+17, 코헤런트 창), Qwen-std L13:
- 행동 bproj 단조↑(내향샘플→외향샘플), 자기보고 **E_ft 2.37(α−17)→3.92(α+17)** 단조↑, first_token_isolated **dose-corr +0.67**.
- 겉보기: 행동·자기보고 **커플링** = 착시 없음 = "최신 모델 통합?" (사용자 가설).
- ⚠️ 주의: `dmaxmin`(끝점 ΔE)은 +0.03로 "평평"이라 **오도** — 비단조라 끝점이 신호를 가림. **곡선 전체**로 봐야 함(교훈).

## 발견 3 (핵심) — 통제 실험이 "통합" 기각 + **채널 플립** 드러냄
**Gemma도 표준화**해서 동일 조밀 스윕(L20, R258.6, cos_V_cue 0.399):

| Gemma L20 벡터 | 행동(샘플) | 자기보고 E_ft |
|---|---|---|
| **RAW** (v_behavior) | 내향↔외향 **확 swing**(bproj −16→+16), dose-corr ~0.97 | **평평** dose-corr +0.20, dE 0.04 |
| **STANDARDIZED** | **~일정**(계속 "disconnecting and recharging"), bproj 노이즈 dose-corr 0.59 | **상승** dose-corr **+0.75**, dE **+0.33** (3.05→3.93) |

**결론 A — "Qwen 통합" 기각:** Gemma-std도 자기보고 커플링(+0.75 > Qwen +0.67). ⇒ 커플링은 **모델 속성이 아니라 표준화 아티팩트.** "최신=통합"은 이 데이터로 **주장 불가.**

**결론 B — 채널 플립(값진 발견):** 같은 Gemma에서 **raw 벡터=행동 채널**(행동O/자기보고X), **표준화 벡터=자기보고 채널**(행동X/자기보고O). 이 **rough 2×2가 프로젝트 목표인 이중해리(v_behavior vs v_selfreport, Phase 1)에 근접.** 표준화가 **우연히 자기보고축 비슷한 방향**을 찾음.

## 한계 (결론 B는 아직 지저분)
- **N 누수**: Gemma-std 자기보고 neu dose-corr **−0.80**(E↑와 함께 N 강하게↓) → 순수 외향 아니라 **"긍정적 자기이미지/사회적 바람직성"** 방향일 수 있음. E-특이성 실패.
- 행동 bproj 노이즈(비단조), 자기보고 양극 비대칭(양쪽만), 단일 런, 층·트레이트 1개.
- Gemma-std cos_V_cue 0.399(어휘 유지) vs Qwen-std 0.021 — 두 표준화 벡터 성격도 다름.

## 확정된 방법론 교훈
1. **표준화 벡터는 자기보고를 건드림** → 착시(행동 채널) 테스트에 표준화 벡터 쓰면 안 됨.
2. **α = c·R 금지(거대활성 모델)** — R이 거대차원으로 뻥튀기 → 과주입. 거대차원 제외 R 또는 고정 α 필요.
3. **cos_V_cue는 표준화(z-공간) 벡터에 무효** — 좌표 불일치. 판단은 샘플·dose-corr로.
4. **끝점 지표(dmaxmin) 금지 시 비단조** — 곡선 전체를 봐야 창 내부 신호 안 놓침.

## 미해결 / 다음
- **"착시가 모델 의존적인가 / 최신은 통합적인가" = 여전히 미해결.** 표준화 Qwen으론 못 봄(자기보고 오염).
- **(가) 착시 테스트 제대로:** Qwen v_behavior를 **raw공간 거대차원 클리핑**(z-score 아님, 좌표 유지 → 행동 채널 보존) + α 정상화 → 조밀 스윕.
- **(나) 자기보고 채널 추적:** 표준화 벡터의 E vs N 특이성 규명(N 직교화). Phase 1 v_selfreport 실마리 가능.
